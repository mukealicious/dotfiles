# Deferred Playbook Catalogue

These are research candidates, not implemented Mu Mode routes. Route matching work through Figure It Out until a local contract is deliberately adopted.

| Candidate | Pstack contract | Why deferred | Likely local adaptation |
|---|---|---|---|
| Eval | Measure whether a skill, structure, or prompt improves agent behavior before promotion. | Needs a separate workflow and credible judging design. | Use organic blinded prompts, configured Pi models, isolated environments, neutral judging, and explicit evidence. |
| Multi-Phase Plan | Shape work spanning phases or stacked PRs before implementation. | Existing local composition already covers much of the need. | Use Figure It Out's [planning recipe](../playbooks/figure-it-out.md#planning-recipe), selecting Grilling, Breadboarding, and vertical slices only as useful; no fixed sequence or dedicated route. |
| Orchestrate | Coordinate a standing, multi-unit program across many agents and delivery units. | Must be distinguished from one-task live-session autonomy. | Explore explicit ownership, state, budgets, resumption, and supervision boundaries. |
| Babysit | Drive an existing PR or stack through review, conflicts, and CI to merge-ready. | Background polling, merge-frontier ownership, and authority need local design. | Separate check, drive, and background modes; preserve explicit gates for pushes, merge, and external communication. |
| Shipping | Independently verify green revisions, then land only the contiguous verified run. | Exact-SHA verification is useful, but pstack's Graphite mechanics are not locally adopted. | Design provider-neutral revision verification and retain explicit merge authority. |
| Worktree Cleanup | Audit and reclaim abandoned worktrees and related local state. | Better treated as a standalone Git maintenance capability. | Begin read-only; classify ownership and merge state, optionally using Herdr context, before any deletion. |
| Autopilot Full | Carry a queue of independent changes through merge with one owner per item. | Autonomy, merge authority, and durable coordination are not established. | Reconsider only after Orchestrate and Babysit have safe local contracts. |
| Autopilot Stack | Build and verify a queue as one linear reviewed stack for later landing. | Graphite methodology is not locally adopted. | Reconsider with provider-neutral stack semantics and explicit operator-owned landing. |

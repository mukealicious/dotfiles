# Exhaust the Design Space

Explore more than one genuinely distinct shape before committing to a consequential decision with no established answer.

- Build or sketch two or three concrete alternatives.
- Make each option opinionated enough to expose its tradeoffs.
- Compare them against the same constraints and user outcome.
- Preserve useful discoveries while selecting one coherent direction.

Apply this to consequential uncertainty, not routine choices. Skip it for mechanical work, clear bug targets, established repository patterns, or constraints that leave only one viable approach. Alternatives may be code, UI prototypes, data models, diagrams, or written interface sketches.

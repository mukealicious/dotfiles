# Local integration instructions

`SKILL.md` is locally authored routing and operating guidance for Pen.dev.
It is not a copy of the `@pen.dev/cli` skill.

An earlier, uncommitted user-supplied CLI skill was removed because its
redistribution permission had not been established. The replacement refers
agents to the installed tool's documentation instead of bundling that text.
No license grant for Pen.dev documentation or software is asserted here.
